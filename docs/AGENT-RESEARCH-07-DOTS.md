**Relationship to Codex (clarified beyond §17):** the direction is the reverse of the one-liner in §17. Dots live in **ChatGPT / Slack / Teams** (texting beta US/CA/MX; not in Business/Enterprise) and **create and manage tasks in Codex and ChatGPT Work**; those delegated tasks are *separate conversations*, billed against normal limits, and **"continuing later or delegating work does not expand"** the authorization originally given. Codex Cloud environments must be created first in Codex, then a dot can use them. The dots' own cloud computer does **not** inherit the member's VPN, browser sign-ins, or device policies. This matters for us: it is a *delegation hierarchy with receipt boundaries* — exactly the shape our S2.3/S2.6 should implement, and the "line blurry" confusion in HN is a product weakness we should not copy.

**Correction worth recording:** §17's phrase "powered by GPT‑6 Astra" is now incomplete — treat dots as *multi-model*, with Astra as the base and Terra/Sol/6.2 routed per work segment. The "GPT‑6.1 Astra shelved" fact remains true and is distinct from Terra/Sol.
