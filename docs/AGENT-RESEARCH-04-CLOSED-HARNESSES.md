# Agent Research 04 — Mechanics of Proprietary / Closed Coding Harnesses

*Research pass 2026-11-17. Sources: official product docs, changelogs, engineering blogs, and dated 2026 reporting. Every mechanic below is sourced; branding is de-emphasized in favor of the transferable mechanism.*

---

## 1. Scope

**Question answered.** What *mechanics* do the closed/proprietary 2026 coding harnesses actually ship — rewind semantics, hooks-as-policy, cache-inheriting subagents, permission UX, checkpoint storage, parallel worktrees, event-driven triggers — and which are worth copying into AI-Harness at an exact `Sx.y` step?

**Baseline (what I did NOT re-report).** `docs/PLAN.md` §17–§21 already cover OpenAI Dots, Grok Bot, and T3 Code deeply; §27.1–27.3 already list the *headline* 2026 features and the five "mistakes we will not repeat." This report assumes that baseline and only adds **new or deeper** detail: the internal mechanics behind those headlines, corrections to attributions, and 2026-product specifics that the baseline only names. Where a mechanism merely restates §27.2 I say so and move on.

**Harnesses in scope:** Claude Code (incl. v2.1.326, 2026-11-16), Cursor 3 / VS Code 1.139, Gemini CLI → Antigravity CLI, Amp (Sourcegraph → Amp Inc.), Windsurf → Devin Desktop, GitHub Copilot CLI / cloud agent / Cowork / Copilot Studio, Grok Build (open core, closed distribution ecosystem), plus the cross-vendor hook-governance layer (Endor Labs, GitGuardian, Failproof, Cedar) as an emergent "meta-harness."

**Out of scope / already covered:** OpenAI Dots and Grok Bot (§17–18), T3 Code source audit (§19), OSWorld/benchmark science (§22). Those remain authoritative in `PLAN.md`.

**Mapping legend.** "Adoption" names the exact step in `docs/IMPLEMENTATION-PHASES.md`. **COPY** = mechanistically proven and cheap for us to adopt; **ADOPT-PRINCIPLE** = copy the idea, not the implementation; **AVOID** = documented flop; **ALREADY-PLANNED** = our plan already contains it (noted so we don't double-build).

## 3. Top 10 "Best Of" mechanics (ranked by leverage for AI-Harness)

1. **Six-way rewind with cache-aware truncation** (Claude Code) — code/conversation/both + summarize-from/up-to, prompt reloaded for re-send, rewind reuses warm KV prefix. Maps to **S1.1 + S2.4**. Highest UX leverage; pair with our stronger git-ref storage.
2. **Hooks-as-runtime-policy with managed-only channel + recursive subagent enforcement + fail-closed** (Claude Code / Copilot / Cross-vendor) — managed hooks locked at root/registry, `onFailure: block`, recursive into subagents, "any deny wins." Maps to **S0.4 + S1.8 + S2.2**.
3. **Declarative tool-risk → confirmation** (Copilot Cowork MCP annotations + Amp checks + T3 compile-time risk) — `readOnlyHint`/`destructiveHint`/unannotated=destructive drives confirm tier; fail closed. Maps to **S0.2 + S0.4 + S2.2**.
4. **Cache-inheriting fork subagents + parallel warm-up hold** (Claude Code forks + workflow fan-out) — derived contexts reuse parent prefix; hold all-but-first ~5s so peers read warm cache; cache cost recorded in receipts. Maps to **S2.3 + S2.4 + S2.8**.
5. **Event-driven subscription agents** (Cursor Projects) — watch Slack/schedule/PRs and act on signals; shared synced context files; coordinator delegates, never executes. Maps to **S5.3 + S2.4 + S2.6**.
6. **Agent Host Protocol / one harness, many surfaces** (VS Code 1.139 AHP + Antigravity unified harness) — same session attached from multiple windows/CLI/desktop; task continuity across surfaces. Maps to **S0.7 + S5.4**.
7. **Editable history = branch point that rewinds files** (Cursor 3.25/3.26) — "Revert files to this message?" with Revert/Keep, later messages removed either way; crash-resumable agents. Maps to **S1.1 + S1.6**.
8. **Portable, Cedar-style declarative policy across vendors** (Endor/GitGuardian/Sondera) — one rule pack, normalized tool names, governed across harnesses; a local-first moat. Maps to **S2.2 + S9.3 + S9.4**.
9. **Thread-ID in commit trailer + handoff-with-relevant-context** (Amp) — audit linkage from git log back to conversation; context-minimal handoff to fresh thread. Maps to **S0.4 + S2.4 + S9.4**.
10. **Code Mode with policy-preserving sub-calls** (Claude Code v2.1.323/326) — JS REPL composes tool calls; every sub-call still traverses deny/ask + hooks; auto-mode reviews the whole script. Maps to **S1.8 + S2.11**. Adopt the mechanism; reject the unverified token-savings marketing.

## 4. Anti-patterns (flops and lessons)

| Anti-pattern | Who / evidence | Lesson for us |
|---|---|---|
| **Kill an open tool for a closed successor without parity** | Gemini CLI → Antigravity (2026-06-18 cutoff, 30-day notice, no 1:1 parity, dead free-tier docs, "not optimized for Gemini 4"). | §27.3 #4 validated. One-version deprecation + dual-run window + parity checklist + signed rollback (**S0.7, S8.7**). |
| **Capability-first, consent-later** | Amp runs all tools without approval; multiplayer shares secrets/files/terminal for a week. | Violates our strictest-sane-defaults rule; keep **deny-by-default + scoped elevation** (**S0.4, S1.3, S1.8**). |
| **Fail-open hooks** | Most vendors fail open on timeout/error; Copilot even fails open for admin policy hooks. | Our policy hooks must **fail closed**; a crashing hook must not silently allow (**S1.8, S2.2**). |
| **Hooks treated as a security boundary** | Endor/CIO/SGit: hooks see intent, not OS effect; one tool's hook bypassed via another; config files editable by the repo. | Capability isolation + egress DLP + scoped credentials is the boundary; hooks are advisory (**S1.8, S1.4**). |
| **Permission-scope overreach** | Copilot "approve for session" on `rm one-file` silently allows any `rm`; Claude v2.1.326 commands run even in bypass mode. | Approval cards must show exact scope; org-level bypass suppression; test bypass mode explicitly (**S1.3, S1.7**). |
| **Silent identity/rebrand/telemetry churn** | Windsurf→Devin rebrand + Cascade removal + telemetry re-enable + March pricing rug-pull; Copilot harness renamed twice; "Grok Build" two products. | Wire-verifiable telemetry opt-out, published pricing, stable naming/docs (**S8.1, S9.4, S9.6**). |
| **Rewind oversold as version control** | Claude Code rewind skips Bash-only changes, subagent edits, symlinks/hardlinks, external edits; Grok checkpoint/compaction fork bug class. | Message rewind as session-level recovery; keep git as source of truth; close symlink gap; make checkpoints compaction-stable (**S1.1, S1.2**). |
| **Unverified savings claims** | Code Mode's "37%" actually comes from a 2025 API post; real Code Mode tests show 11–55% but slower runs. | Report Pass^k/CIs with benchmark versions; never attach a borrowed number to a new feature (**S1.9, S8.9**). |
| **Project plugins can override admin policy** | Amp project plugins take precedence over system/personal/workspace; no admin lock. | Enforce managed > workspace > project precedence (**S2.2, S1.8**). |
| **Cloud storage of code as a privacy-mode tradeoff** | Cursor Projects unavailable under Privacy Mode (Legacy) because cloud agents store code; self-hosted workers stream file contents/diffs/screenshots up. | Our local-first posture is the differentiator; make "what leaves the machine" explicit and wire-verifiable (**S1.8, S7.4, S9.4**). |
