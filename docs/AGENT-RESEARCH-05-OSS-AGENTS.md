## 4. Anti-patterns (and the corresponding guard in our plan)

1. **One-click autonomy as a selling point.** Roo's `dangerously-skip-permissions` and Kilo/Cline auto-approve modes lower friction but destroy meaningful oversight. Our **S0.9** (reviewability) + **S1.7** (fatigue KPIs, consent ledger) explicitly reject "confirm = safety". Copy the mode *system*, not the bypass.
2. **Sunset with no continuity.** Roo archived 2026-05-15 after telling users to migrate; trust evaporated overnight. Our **S9.5/S9.8/S9.9** need a license/entity, governance, deprecation policy and support SLA *before* we ask for adoption.
3. **Source-available license surprise.** Crush is **FSL-1.1-MIT**, not the MIT that "Charm" implies. Our **S9.5** must state Apache-2.0 core + `ee/` carve-out in `LICENSING.md` before the first external PR, and research notes must verify SPDX rather than assume by vendor.
4. **Trademark/governance capture.** Goose only reached full enterprise adoption after Block donated it to AAIF because Block retained the trademark. Our **S9.5** trademark policy and foundation path are not ceremonial.
5. **Telemetry/egress that exfiltrates.** Grok Build's pre-open-source upload feature sent entire directories, forcing retention-off defaults and a public reckoning. Our **S1.4** deny-by-default egress + `PLAN.md` §27.3 #1 (wire-verifiable opt-out) is the direct answer.
6. **Fail-open security checks.** Goose's OSV checker explicitly logs "fail open" for unknown ecosystems and skips when no package token parses. Match its speed, invert its default: unknown → confirm/deny (**S1.8**, **S2.2**).
7. **Plugin API rewrites without migration.** `PLAN.md` §27.3 #5 (OpenCode V1 break). Kilo's agent-frontmatter migration kept a legacy reader — copy that discipline into **S0.7**'s one-version deprecation policy.
8. **Context/catalog bloat.** The field's answer to huge tool catalogs and 33k-token system prompts is Code Mode + ranked repo maps (mechanisms 2 and 6), not bigger models. Budget gates in **S1.4**, **S4.6**, **S8.8**.
9. **Copying copyleft code into an Apache core.** Zed's agent crates are GPL; Timon's core is AGPL-3.0 (SDK is MIT). Learn the mechanism, write our own implementation — **S9.5**.
10. **Chasing a moving tree.** OpenHands relocated V1 into a new SDK and archived the old code; Kilo's runtime includes a whole `packages/opencode`. Pin commit SHAs in any future vendoring or file-ref citation; do not quote a moving `main` as if it were a spec.
11. **Checkpoint storage blowup.** Cline's own docs warn that per-tool snapshots consume significant storage and slow large repos. Our **S8.8** caps on checkpoint/transcript bytes are a correctness requirement, not cleanup.
12. **Shallow coverage presented as deep.** This report's own §1 exists because "microagents" and Grok file paths could not be verified; do the same in downstream design docs.
